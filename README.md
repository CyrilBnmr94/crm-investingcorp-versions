# Installer le CRM Investingcorp

Installateurs de l'application. Ce dépôt ne contient aucun code source ni aucune donnée.

Compter cinq minutes.

## 1. Télécharger

Ouvrir la page des versions : https://github.com/CyrilBnmr94/crm-investingcorp-versions/releases/latest

Dans « Assets », télécharger le fichier qui finit par `universal.dmg` (il fonctionne sur tous les Mac récents).

## 2. Installer

1. Ouvrir le fichier téléchargé.
2. Glisser « CRM Investingcorp » dans le dossier « Applications ».
3. Éjecter le disque « CRM Investingcorp » (flèche à côté de son nom dans le Finder).

## 3. Autoriser l'application, la première fois seulement

L'application n'est pas vendue sur l'App Store : au premier lancement, macOS affiche « Apple n'a pas pu vérifier… ». C'est normal.

1. Cliquer sur « Terminé » (ou « OK »).
2. Ouvrir « Réglages Système », puis « Confidentialité et sécurité ».
3. Descendre jusqu'à la ligne « CRM Investingcorp a été bloqué » et cliquer sur « Ouvrir quand même ».
4. Confirmer avec le mot de passe du Mac, puis « Ouvrir ».

Sur un Mac plus ancien (macOS 14 ou avant), on peut aussi faire un clic droit sur l'application, « Ouvrir », puis « Ouvrir ».

Ensuite, l'application s'ouvre normalement, sans cette question.

## 4. Premier lancement

1. Créer le code d'accès (au moins 6 caractères). Il n'existe pas de récupération : le noter en lieu sûr.
2. Les sauvegardes partent automatiquement dans iCloud Drive › CRM Investingcorp › Sauvegardes. Le dossier se change dans « Réglages ».

## Mises à jour

Quand une nouvelle version est publiée, un bandeau bleu l'annonce à l'ouverture. « Installer et redémarrer » sauvegarde d'abord les données, installe, puis relance l'application. Les données sont conservées.

## Nouveau Mac ou Mac réinstallé

Installer l'application comme ci-dessus, créer un code provisoire, puis dans « Réglages » choisir le dossier iCloud des sauvegardes et restaurer la plus récente. Le code d'accès redevient celui d'avant.
